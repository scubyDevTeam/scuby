# Open Items

> Decisions not yet made (**Open**) and decisions made as "not now" (**Deferred**), across all
> docs. One place, so nothing lives only as a sentence inside a flow doc. Each item links to where
> it bites. When an item closes, write the decision into the owning doc and delete the row here.
>
> **The v1 contract:** the docs in `product/` and `eng/` describe what v1 builds. Anything in the Deferred table does
> **not** exist in v1 — no schema, no enum value, no endpoint — unless a flow doc explicitly ships
> a seam early (e.g. adoption's `lane`). When implementing, treat a D-row as documentation of the
> future, never as a requirement.
