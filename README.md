# scuby

Plataforma para mascotas perdidas, encontradas, en adopción y con pedidos de ayuda. Colombia
primero, nunca solo Colombia. Proyecto de dos ingenieros (10–15 h/semana), con la documentación
primero.

| [`web/`](web/README.md) | Cliente web y PWA: estructura, cómo correrlo y cómo se construye una funcionalidad |

Empieza por `docs/product/00-product-map.md` (misión, principios y registro de decisiones) y por
[`web/README.md`](web/README.md).
